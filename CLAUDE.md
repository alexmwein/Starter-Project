## Skill routing

When the user's request matches an available skill, invoke it via the Skill tool. When in doubt, invoke the skill.

Key routing rules:
- Product ideas and brainstorming: invoke /office-hours
- Strategy and scope: invoke /plan-ceo-review
- Architecture: invoke /plan-eng-review
- Design system and plan review: invoke /design-consultation or /plan-design-review
- Full review pipeline: invoke /autoplan
- Bugs and errors: invoke /investigate
- QA and site behavior testing: invoke /qa or /qa-only
- Code review and diff checks: invoke /review
- Visual polish: invoke /design-review
- Ship, deploy, and pull requests: invoke /ship or /land-and-deploy
- Save progress: invoke /context-save
- Resume context: invoke /context-restore
- Author a backlog-ready specification or issue: invoke /spec
