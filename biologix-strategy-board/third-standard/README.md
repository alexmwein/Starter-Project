# Third Standard

Third Standard is a pre-launch controlled-access B2B analytical reference material and Lot Record concept.

## Public site

- `index.html` — homepage
- `catalog.html` — material-class preview; no fake inventory
- `lot-record.html` — interactive documentation schema
- `access.html` — local-only access-file generator
- `notes.html` and `notes/coa-boundaries.html` — evidence publication
- `company.html` — company doctrine and claims policy
- `eligibility.html` — qualification boundary
- `404.html` — missing record state

The entire site is static HTML, CSS, and JavaScript. The access form creates a text file locally using a browser Blob and transmits nothing.

## Source documents

The company strategy, roadmap, marketing plan, competitive intelligence, operating model, launch gates, economics, and Fable 5 design authority live in `docs/third-standard/`.

## Launch status

Concept only. The website is intentionally explicit that it does not offer products, accept applications, claim inventory, or present sample data as real evidence.
